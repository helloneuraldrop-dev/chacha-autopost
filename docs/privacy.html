Privacy Policy: Chacha Kanjoos Autopost

Last updated: 20 November 2026

Chacha Kanjoos Autopost is a private tool used only by the owner of the Chacha Kanjoos channel to upload the channel's own videos.

What it accesses

With the owner's permission (Google OAuth), it uses the YouTube Data API to upload videos to the owner's own channel and to read that channel's name to make sure uploads go to the right channel. It does not read, collect or store data about viewers or any other users.

Storage

The only stored credential is the owner's OAuth refresh token, kept as an encrypted secret in the owner's GitHub repository. Upload results (video IDs and links) are stored in the same repository. Nothing is sold or shared with anyone.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
